**1. AI Dashboard Insights — /api/insights/route.ts**
- GET endpoint with requireAuth() authentication
- Fetches user's investments (with asset details), dividends, transactions from DB in parallel
- Aggregates portfolio data: total invested, current value, dividends (paid/pending), ROI, composition by asset type
- Sends comprehensive Spanish system prompt requesting 4-5 typed insights (performance, diversification, dividend, recommendation, alert)
- Uses glm-4-flash model for fast response
- Parses JSON response with regex extraction and validation
- 30-minute in-memory cache per user (Map<string, { insights, expiresAt }>)
- Robust fallback generator when SDK unavailable: generates 5 static insights from real portfolio data
- Returns: { insights: [{ type, title, message, metric?, metricValue?, priority }] }

**2. AI Semantic Asset Search — /api/assets/search/route.ts**
- GET endpoint (public, no auth) accepting ?q=search+query&limit=10
- Fetches all active assets from DB with 25+ fields for semantic context
- Sends Spanish system prompt instructing LLM to return matching asset IDs with relevance scores
- Includes asset name, type, city, region, price, yield, risk, description, highlights, tags in prompt
- Uses glm-4-flash with temperature 0.3 for consistent ranking
- Validates returned IDs against actual asset IDs before querying full details
- Fetches full asset details (with cover images) for matched IDs, preserves LLM ranking order
- 10-minute in-memory cache per normalized query
- Fallback: synonym-aware text search (maps apartment↔departamento, office↔oficina, etc.) with weighted scoring across 7 fields
- Returns: { results: Asset[], query: string, total: number }

**3. AI Regulatory Compliance Report — /api/compliance/report/route.ts**
- GET endpoint with requireAdmin() authentication
- Fetches 18 platform metrics in parallel: user counts, KYC stats, investment aggregates, transaction volumes, dividend totals, risk profile coverage, terms acceptance, audit logs
- Sends detailed Spanish system prompt requesting 6-section compliance report covering KYC, AML, investor suitability, transaction monitoring, data protection, and summary
- Uses glm-4-plus model for comprehensive analysis
- Validates section statuses (compliant/warning/non-compliant) after parsing
- 1-hour in-memory cache (compliance reports don't change frequently)
- Robust fallback generator: creates 6 sections with real platform numbers and dynamic status calculation (threshold-based)
- References Chilean regulations: CMF, Ley 19.913 (AML), Ley 19.628 (Data Protection)
- Returns: { report: string, sections: [{ title, content, status, items[] }], generatedAt: string }
